# EVENTIFY – Event Management Website

## 1. Project Description

Eventify is a modern event discovery and management website developed using ReactJS.

The website allows users to explore upcoming events, search for events, filter events by category, and view detailed information about each event.

The goal of Eventify is to provide users with a simple and attractive platform to discover events and find experiences they enjoy.

## 2. Technologies Used

- ReactJS
- JavaScript
- HTML5
- CSS3
- Bootstrap 5
- React Router
- Vite
- Git and GitHub

## 3. Main Features

- Home page with an attractive design.
- About page introducing Eventify.
- Events page displaying upcoming events.
- Search functionality to find events.
- Category filtering (Music, Technology, Art, and Sports).
- Dynamic event details pages.
- Contact page with a contact form.
- Responsive design for different screen sizes.

## 5. Setup Instructions

Follow these steps to run the project locally.

### Step 1: Clone the repository

```bash
git clone https://github.com/52430458-tech/Eventify-react-project.git
```

### Step 2: Open the project folder

```bash
cd Eventify-react-project
```

### Step 3: Install dependencies

```bash
npm install
```

### Step 4: Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
